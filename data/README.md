# Testdokumentation

Mappen indeholder **fiktiv** intern dokumentation for en opdigtet virksomhed. Den bruges som
testdata til RAG-pipelinen og evalueringssættet i fase 2.

Erstat filerne med jeres rigtige dokumentation (Markdown eller tekst), og kør `POST /ingest`
igen. Husk at opdatere evalueringssættet i `docs/evaluering/`, så facit passer til de nye dokumenter.

Alle tal, navne og systemer i dokumenterne er opfundne.
